# CRUD Map: Stray Alert MVP

## Table CRUD Operations

| Table | C | R | U | D | Pages | Who |
|-------|---|---|---|---|-------|-----|
| owners | ✓ | ✓ | ✓ | – | register.html, dashboard.html, admin/users.html | Self: C, U · Admin: R, U, D (deactivate) |
| pets | ✓ | ✓ | ✓ | ✓ | pets/form.html, pets/detail.html, pets/feed.html, admin/pets.html | Owner: C, R, U own · Admin: all |
| qr_tags | ✓ | ✓ | – | – | pets/tag.html, pets/scan.html | Owner: R · Admin: all (auto-generated on pet create) |
| reports | ✓ | ✓ | ✓ | – | lostfound/form.html, lostfound/index.html, lostfound/detail.html, admin/reports.html | Public: C (found) · Owner: C (lost) · Admin: R, U (resolve) |

**Notes:**
- owners: No delete - accounts are deactivated instead (is_admin or status field)
- qr_tags: Auto-generated when pet is created, no manual delete (cascade delete with pet)
- reports: Kept as history, never deleted - status changes from Open to Resolved
